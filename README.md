# 🏆 Sports Event Management System (GoWeb)

Учебный дорабатываемый веб-проект для организации и управления спортивными событиями, разработанный на современном стекe .NET.

## 🚀 Технологический стек

* **Backend:** C#, ASP.NET Core Web API, Entity Framework Core, LINQ.
* **Паттерны и библиотеки:** CQRS (MediatR), AutoMapper, MemoryCache.
* **Frontend & Mobile:** Blazor WebAssembly, .NET MAUI (Blazor Hybrid), Razor Components.
* **База данных:** MySQL через Entity Framework Core (Pomelo.EntityFrameworkCore.MySql).
* **Инфраструктура & DevOps:** Docker, Docker Compose, GitHub Actions (CI/CD), GitHub Container Registry.

## 💡 Ключевые особенности и архитектура

* **Безопасность и авторизация:**
  * JWT-аутентификация 
  * **Ресурсно-зависимая авторизация (Resource-Based Authorization):** гибкая система проверки прав через `IAuthorizationService`, кастомные требования (`IAuthorizationRequirement`) и обработчики (`AuthorizationHandler`).
  * Разграничение прав на уровне UI и API: редактировать или удалять событие может только его непосредственный **Организатор** или пользователь с ролью **Администратор**.
* **Автоматизация бизнес-процессов (Фоновые задачи):**
  * Использование встроенных **BackgroundService** (`IHostedService`) для автоматического закрытия завершенных мероприятий, автоматической отмены при недостаточном количестве участников и пересоздания регулярных событий без участия пользователя.
* **Кроссплатформенность и переиспользование кода:** 
  * Разделение на клиентскую, серверную и общую (`GoWeb.Shared`) части.
  * **Параллельное внедрение .NET MAUI (Blazor Hybrid):** мобильное приложение напрямую переиспользует UI-страницы и Razor-компоненты из библиотеки `GoWeb.Shared`, обеспечивая единую кодовую базу для веб-клиента и мобильных платформ.
* **CI/CD Пайплайны:** Настроена автоматическая сборка Docker-образов и деплой на сервер с помощью GitHub Actions.
